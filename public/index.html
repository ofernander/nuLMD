Metadata Retention

How long cached artist/album metadata stays fresh before nuLMD re-fetches it from MusicBrainz on the next Lidarr request. Default 30 days.

Metadata Blocklist

Artists, release groups and releases nuLMD never fetches or stores, and never queues a job for. Block one from the Metadata Browser, or add it here by MusicBrainz ID (the only way to block a single release). Anything in Lidarr's library cannot be blocked.
